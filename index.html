Cybersecurity - SOC / Security Operations

My interest in cybersecurity started during my Information Security internship, where I got hands-on experience working with security processes and practices. I’ve continued building on that experience beyond the workplace through hands-on labs, security projects, CTFs, and practical exercises. I’m particularly interested in security operations, threat detection, vulnerability management, and security engineering. I use this portfolio to document what I’m learning, the projects I build, and the security work I explore along the way.
